# A.I.G（AI-Infra-Guard）

## Description
A.I.G (AI-Infra-Guard) is a comprehensive, intelligent, and user-friendly AI red teaming platform developed by Tencent Zhuque Lab, designed to provide users with a one-stop solution for AI security risk self-assessment.

Key Features and Capabilities:

AI Infra Scan: Precisely identifies over 30 AI framework components, covering nearly 400 known CVE vulnerabilities in frameworks like Ollama, ComfyUI, and vLLM.

MCP Scan: Driven by an AI Agent, it can detect 9 major categories of MCP security risks, such as tool poisoning and indirect prompt injection, and supports both source code analysis and remote URL scanning.

Jailbreak Evaluation: Includes multiple high-quality assessment datasets and jailbreak attack algorithms. It can rapidly generate LLM red teaming reports and supports exporting detailed reports for security alignment and guardrail reinforcement
